Entry for the [One Emoji, One Smile](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f) competition on make.fun.

The program (`main.py`, Python 3 stdlib only, fully offline and deterministic) writes exactly one emoji to `/output/entry.txt`: 🫶 heart hands — a warm, open gesture of friendliness, chosen as the emoji most likely to make a stranger smile.

## Run

```sh
python3 main.py
```
